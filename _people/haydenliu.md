Yuxi (Hayden) Liu is a Software Engineer focused on Machine Learning at Google. He develops and improves machine learning models and systems for ads optimization on the largest search engine in the world, working at the scale problems, data pipelines, and ranking systems that few environments can match.

Hayden is also a recognized author in the machine learning community. His book, Python Machine Learning by Example, takes a learn-by-doing approach to practical machine learning, walking readers through real projects with Python, scikit-learn, and PyTorch, from classic algorithms to deep learning and NLP. The book has become a popular entry point for developers and data scientists who want to move from theory to working code.

The combination of production ML engineering at massive scale and clear technical teaching defines Hayden's career. He writes and builds with the same philosophy: machine learning is best learned, and best built, by example.
