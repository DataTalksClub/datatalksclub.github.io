Violetta Mishechkina is a Python Developer and Solution Engineer at dltHub, the company behind dlt, the open source data load tool for Python. In her role she works at the intersection of engineering and customer problem-solving, using Python to help teams move data reliably from where it is created to where it creates value.

As a solution engineer for an open source data tool, she sits right where developers and users meet: close enough to the code to understand what the library can do, and close enough to users to understand what they actually need.
